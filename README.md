# Estação Revalida

Site institucional estático de apresentação da mentoria virtual. HTML, CSS e JavaScript, sem instalação ou build.

## Publicar na Vercel

Importe este repositório, escolha **Other** como Framework Preset, mantenha a raiz e deixe os comandos de build e instalação vazios. O arquivo index.html é a página inicial.

## Conteúdo

- Apresentação da mentoria com identidade azul-marinho, turquesa e dourado.
- Formulário de interesse, WhatsApp e Instagram fornecidos pelo responsável.
- Reflexões interativas, menu móvel e perguntas frequentes.
- Sem login, coleta própria de dados, pagamentos ou confirmação de matrícula.

## Pendências editoriais

A marca atual é tipográfica. Adicionar a logo oficial fornecida como arquivo de imagem antes da versão final.
